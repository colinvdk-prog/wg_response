## The rules

**Satellite heat only (41, `hotspot_heat_only`, watch `--hotspot-heat-only`).** Right after the
hotspot attachment (39), an incident only the satellite reports is split off: source FIRMS,
`firms` its only source id, and not seeded. Such an incident leaves the forecast set. It gets no
domain, ETA, alert, dispatch job, belief observation or learning forecast.

- **On the map:** it is listed after the forecast fires, with the note "satellite heat only — no
  forecast or alerts until screened".
- **Earlier alerts:** a pair it raised before takes the absence law, so it clears after
  `clear_cycles` while the feeds are healthy. It is not treated as blind: the cluster left by
  rule, not because a provider failed.
- **Operator note:** heat within `hotspot_heat_note_m` (8 km) of a protected home is listed
  every cycle for the operator: `/api/state` `heat_near_homes` and the map's "heat near homes"
  chip, nearest first, with details on hover. When a cluster comes into range it is also one
  `satellite_heat` operator event. It is never a client message and never a degradation.
- **Reported fires:** detections on a reported fire still join it and seed its forecast.

**Domain snap (42, `forecast_domain_snap_deg`, watch `--snap-domains` = 0.05°).** The padded
domain is snapped outward before the cell size is picked. A shape that stays inside the same
snapped box asks for the same tile. The domain grows by less than one grid step a side
(0.05° = 5.6 km north–south).

**The terrain turn (40).** The cycle holds the turn while it assesses. A learning forecast starts
only once the turn is free, so the cycle's own LANDFIRE jobs are never queued behind a learning
forecast that started during the assess phase. One already started runs on.

**Dispatch with no eligible crew.** The planner skips the corridor erosion. Every job is unserved
for capacity and no leg is checked, so the plan is the same; only the wait goes.

## What this does not settle

- The screening protocol itself (tiers, the tripwire distance, satellite-only dispatch, Rx burns,
  confirm/dismiss staffing) is still the founder's open decision. Heat only is the interim
  posture: what a satellite alone sees near a home is the operator's to watch, not the ladder's.
- WFIGS and FIRIS read timeouts (world16's 7.7-min feeds) are not addressed here.
